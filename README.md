# Kentico to Umbraco Migrator

A command-line tool that reads a Kentico 11 site directly from SQL Server and recreates its pages,
media and old URLs in Umbraco 17 through the Management API. Runs are repeatable and verified with
before/after counts.

Work in progress. See the [specification](specs/001-kentico-umbraco-migrator/spec.md).
