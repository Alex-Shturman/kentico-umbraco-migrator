# Status is the first response without following redirects. The final path is where the request ends:
# the Location header for 301, the request path itself for 200 and 404. Old URLs are percent-encoded.
# Verified Umbraco 17 routing (Track 1): routing is case-insensitive, so a path that differs only in
# case is a 200 without a redirect; document URLs are lower case with a trailing slash, and a redirect
# Location is relative with that trailing slash (so 301 targets below end in "/"); the host itself
# redirects .aspx paths. Every line was confirmed against a real run (T055); the one correction is /Home, see below.
